# short-cut-filter-effect-plugin

AviUtl2（ExEdit2）の表示に `short-cut-filter-effect-plugin` を追加する汎用プラグインです。
オブジェクト編集画面で右クリックしたフィルタ効果を 1〜10 のスロットに登録し、ボタンまたは `Ctrl+1`〜`Ctrl+9` / `Ctrl+0` で選択中オブジェクトへ反映します。

## 機能

- `short-cut-filter-effect-plugin` ウィンドウに 1〜10 のボタンを横並び表示
- 幅が足りない場合は横スクロールバーを表示
- ウィンドウ上のマウスホイールで横スクロール
- フィルタ効果の右クリックメニューに `フィルタ効果をショートカットプラグインに登録` を追加
- 子メニューの 1〜10 を選ぶと、右クリックしたフィルタ効果の現在値を同じ番号のボタンに登録
- 登録済みボタン、または `Ctrl+1`〜`Ctrl+9` / `Ctrl+0` で、現在選択しているオブジェクトの同名フィルタ効果へ登録値を反映
- 選択オブジェクトに同名フィルタ効果が無い場合は、オブジェクト alias に登録済みフィルタ効果を追加して差し替えます
- 選択オブジェクトに追加できないフィルタ効果の場合は、元のオブジェクトを復元します
- 登録内容はプロジェクトファイル内に保存されます

## 追加方式

AviUtl2 SDK の公開 API では、既存オブジェクトへフィルタ効果そのものを新規追加する関数が公開されていません。
そのため、同名フィルタ効果が既にある場合は SDK の `set_object_item_value()` で値を反映し、無い場合は選択中オブジェクトの alias を取得して登録済みフィルタ効果ブロックを追加した alias に差し替えます。
差し替え作成に失敗した場合は元の alias で作り直します。

## ビルド

Visual Studio 2022 の「C++ によるデスクトップ開発」と CMake を使用します。

```powershell
cmake -S . -B build -A x64
cmake --build build --config Release
```

生成物は `build/Release/short-cut-filter-effect-plugin.aux2` です。
